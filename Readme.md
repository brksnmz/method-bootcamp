SRI Quantitative Methods Bootcamp
=================================

What is in this folder
- SRI Quantitative Methods Bootcamp.pdf   the slides
- Bootcamp.Rproj                          the RStudio project: open this first
- Example-script.R                        your practice script for the R workshop
- R-workshop.R                            worked examples and exercise solutions
- WDI_Data.csv                            the dataset

Before the session
1. Install R, version 4.1 or later: https://cloud.r-project.org/
2. Then install RStudio Desktop: https://posit.co/download/rstudio-desktop/
3. Unzip this folder somewhere you can find it again. Do not open the files
   from inside the zip.
4. Double-click Bootcamp.Rproj. RStudio opens in this folder.
5. In the RStudio Console, run this line once to install the packages:
   install.packages(c("readr", "dplyr", "ggplot2"))
6. Open Example-script.R. Run a line with Ctrl + Enter (Windows/Linux)
   or Cmd + Enter (Mac).

Keep all these files together in this folder. The scripts save their results
to a new "outputs" folder here.
